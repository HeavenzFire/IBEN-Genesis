## Evidence before claims

We distinguish implemented code from tested behavior, CI verification, independent reproduction, benchmarked advantage, and external validation. Passing tests do not establish life-critical readiness or prove a research hypothesis. See the operating principles for the evidence labels and safety boundaries.

## Security

Never commit API keys, signing keys, tokens, or other secrets. Rotate any credential that has entered public history; deleting a file from the latest revision does not remove earlier copies.
